## 1. 排版目标态核心规范

### 1.1 标题层级递进（禁止断层跳级）
1. 全文最高标题为一级标题（`# 标题`），单文档原则上仅出现一次主标题。
2. 章节标题遵循严格递进关系（`#` → `##` → `###` → `####`），严禁从 `#` 直接跳跃至 `###`。
3. 标题行上方与下方必须保留且仅保留一个空行。
4. 编号类标题（如“一、概述”、“1.2 技术指标”）必须与标题层级符号之间保持清晰空格。

### 1.2 段落与换行规范（智能消除硬断行）
1. 中文文档由于原排版断行导致的换行，必须结合句末标点（。！？；：）进行自动拼接合并。
2. 英文与数字混排段落保持自然词间距，不得产生生硬拼接。
3. 段落之间保留单空行，严禁出现连续两个或以上的空行。

### 1.3 表格语法保护与完整性
1. Markdown 表格必须包含完整的表头、分隔线（`|:---|:---|`）与数据行。
2. 表格行的每一列在语法上受绝对保护，整理器严禁将表格内的换行与正文段落混合粘连。
3. 单元格内部的原生换行统一转换为 `<br>` 或空格，确保每行仅对应 Markdown 表格的一个逻辑行。

### 1.4 资产与图片引用
1. 严禁在 Markdown 正文中保留 base64 格式的内联超长文本。
2. 所有提取出的图片资源统一落盘为外部文件，并转换为相对路径引用：`![说明](assets_<基名>/图片名.png)`。

## 2. 质量门禁规则码全量清单（md_lint 实装 34 条规则）

分为 **7 项 E 级阻断**、**23 项 W 级警告** 与 **4 项 I 级提示**：

| 规则码 | 级别 | 严重度 | 含义与判定标准 |
| :--- | :--- | :--- | :--- |
| `E-ENC-01` | **E 级** | 阻断 | 非 UTF-8 编码或带有 UTF-8 BOM 签名 |
| `E-STR-01` | **E 级** | 阻断 | H1 一级标题缺失或不唯一 |
| `E-STR-02` | **E 级** | 阻断 | 标题层级发生跨级跳跃（如从 `#` 直接跳到 `###`） |
| `E-TBL-01` | **E 级** | 阻断 | 表格块缺失表头分隔行（`\|:---\|`） |
| `E-TBL-02` | **E 级** | 阻断 | 表格数据行与表头列数严重不一致 |
| `E-IMG-01` | **E 级** | 阻断 | 正文引用的图片相对路径在本地资产目录中不存在 |
| `E-LOSS-01` | **E 级** | 阻断 | 字符多重集比对丢失核心内容字符（相对源文档丢字） |
| `W-ENC-02` | **W 级** | 警告 | 文档中混用 CRLF 与 LF 换行符 |
| `W-ENC-03` | **W 级** | 警告 | 行尾存在多余空白字符（空格/制表符） |
| `W-ENC-04` | **W 级** | 警告 | 文件结尾缺失末尾换行符 |
| `W-STR-03` | **W 级** | 警告 | 标题以句号/逗号等不规范标点结尾 |
| `W-STR-04` | **W 级** | 警告 | 标题疑似与后续正文黏连未分行 |
| `W-STR-05` | **W 级** | 警告 | 正文中存在疑似未标记 Markdown 语法的孤立编号标题 |
| `W-PAR-01` | **W 级** | 警告 | 正文存在超长行且缺少句末停顿标点 |
| `W-PAR-02` | **W 级** | 警告 | 存在孤立残片行（不足3字符的残断文本） |
| `W-PAR-03` | **W 级** | 警告 | 连续空行超过 1 行 |
| `W-TBL-03` | **W 级** | 警告 | 表格行内存在相邻完全重复的单元格 |
| `W-TBL-04` | **W 级** | 警告 | 表格中存在相邻完全重复的数据行 |
| `W-TBL-05` | **W 级** | 警告 | 表格包含全空行或尾部多余空列 |
| `W-TBL-06` | **W 级** | 警告 | 表格空壳行（仅首列有内容，其余全空） |
| `W-TBL-07` | **W 级** | 警告 | 表格块与正文上下文之间缺失空行分隔 |
| `W-IMG-02` | **W 级** | 警告 | 图片引用的 alt 文本为空 |
| `W-IMG-03` | **W 级** | 警告 | 图片未独立成段，与文本混排在同一行 |
| `W-IMG-04` | **W 级** | 警告 | 图片路径为绝对路径或包含 Windows 反斜杠 `\` |
| `W-PG-01` | **W 级** | 警告 | 存在独立页码行残留（如 `- 12 -`、`12/45`） |
| `W-PG-02` | **W 级** | 警告 | 行首残留页码竖线或分隔符号 |
| `W-PG-03` | **W 级** | 警告 | 标题行尾部残留页码数字 |
| `W-PG-04` | **W 级** | 警告 | 目录导引点线（如 `...... 12`）残留 |
| `W-PUN-01` | **W 级** | 警告 | 中文语境下混杂使用半角逗号或句号 |

| `I-IMG-05` | **I 级** | 提示 | 图片采用 base64 内联超长字符串存储 |
