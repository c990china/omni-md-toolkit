# 标题黑名单（md_reorganizer classify_section 专用）
#
# 用途
# ----
# `md_reorganizer` 靠「行长 + 标点 + 关键词」猜哪些行是章节标题，会把某些**正文短句**
# 误升为 `##`。电子书场景尤其明显：抽取端（kindle_to_md）已按 calibre 的 class
# 正确还原了全部真标题，但自整理的启发式仍可能把正文里的短句当成标题。
#
# 实测案例
# --------
# 「现在是时候把大象提出来了」——原文是**正文段落**（`part0009.xhtml` 里的
# `<p class="calibre3">`），位于「进展和知识」章中间，却被提升成 `##`，
# 在目录 16 章之外多出一个不存在的章节。
#
# 怎么用
# ------
# 每行写一条**完整标题文字**（须与文中该行完全一致，含标点），匹配后该行不再被提升为标题。
# 以 `#` 开头的行是注释。文件不存在时功能静默关闭，不影响其他格式。
#
# 维护约定
# --------
# 1. 只登记**确认是正文、却被误升为标题**的句子；不要用来排除真标题。
# 2. 登记前先确认抽取端没给错（电子书应看 `kindle_to_md` 的 class 判定结果），
#    否则可能是抽取端的 bug，应修抽取端而不是加黑名单。
# 3. 修复后请重跑 `md_lint.py`，确认没有引入 E 级丢字。
